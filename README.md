# RezaShop — Static Persian E-commerce Page

A static Persian (RTL) e-commerce landing page built with HTML, CSS and vanilla JavaScript.

## Features

- Hero slider (Swiper)
- Navigation: صفحه اصلی، پشتیبانی، تماس با ما، درباره ما
- Category navigation (e.g. گوشی، سامسونگ)
- Product grid with cards, pricing UI and promotional banners
- Responsive layout (flexboxgrid)

## Getting started

No build step — just open `index.html` in a browser.

## Tech

- HTML5, CSS3, JavaScript
- Swiper, flexboxgrid
